# Deiboard - 个人音乐榜单管理工具

### 🚀 项目简介
这是一个基于 AI 驱动开发（Prompt Engineering）的轻量级 Web 工具，旨在解决个人音乐爱好者在制作周榜时数据统计繁琐、排版困难的痛点。

### ✨ 核心功能
- **自动化排序**：支持通过简单的拖拽或排名输入实现榜单重排。
- **智能数据处理**：利用正则表达式自动拆分合作歌手（feat./&）。
- **效率提升**：将原本需 60 分钟的手工统计流程缩短至 10 分钟内。
- **本地存储**：基于 LocalStorage 实现无后端的数据持久化，保障数据不丢失。

### 🛠️ 技术实现
- **开发模式**：由本人担任产品经理与提示词工程师（Prompt Engineer），利用 Gemini 进行逻辑实现与代码生成。
- **核心技术**：原生 JavaScript (ES6), CSS Variables, HTML5, LocalStorage.
